# Keybinds

All of these live in [`home/.config/mango/config.conf`](home/.config/mango/config.conf), so `install.sh` sets them up automatically. **Super** is the Windows key.

## Apps

| Keys | Action |
|---|---|
| Super + Enter | Terminal (kitty) |
| Super + Q | Terminal (kitty) |
| Super + N | Claude in a terminal |
| Super + Space | App launcher (rofi) |
| Super + E | File manager (Dolphin) |
| Super + Alt + F | Firefox |
| Super + R | Wallpaper picker (also recolours the whole theme) |

## Windows

| Keys | Action |
|---|---|
| Super + W | Close window |
| Super + Arrow keys | Move focus |
| Super + Tab | Next window in stack |
| Super + Shift + Arrow keys | Swap window in that direction |
| Super + V | Toggle floating |
| Super + F | Fullscreen |
| Super + Shift + F | Maximise |
| Super + S | Scratchpad |
| Ctrl + Alt + Arrow keys | Resize window |
| Super + Alt + G | Toggle gaps |
| Super + Left mouse drag | Move window |
| Super + Right mouse drag | Resize window |
| Middle click | Maximise |

## Layouts

| Keys | Action |
|---|---|
| Super + J | Cycle layout |
| Super + Shift + Alt + 1 | Tile |
| Super + Shift + Alt + 2 | Dwindle |
| Super + Shift + Alt + 3 | Scroller |
| Super + Shift + Alt + 4 | Grid |
| Super + Shift + Alt + 5 | Monocle |
| Super + Shift + Alt + 6 | Deck |
| Super + Shift + Alt + 7 | Fair |
| Super + Shift + Alt + 8 | Right tile |

## Workspaces (tags) and monitors

| Keys | Action |
|---|---|
| Super + 1–9 | Go to workspace |
| Super + Shift + 1–9 | Move window to workspace |
| Super + Z / X | Previous / next workspace |
| Super + Shift + Z / X | Move window to previous / next workspace |
| Super + Scroll up / down | Previous / next workspace with windows |
| Super + Ctrl + Left / Right | Focus other monitor |
| Super + Alt + Left / Right | Move window to other monitor |

## Screenshots

| Keys | Action |
|---|---|
| Print | Screenshot menu |
| Super + A | Screenshot menu |
| Shift + Print | Region |
| Super + Print | Active window |
| Ctrl + Print | All screens |

## Media and hardware keys

| Keys | Action |
|---|---|
| Play / Next / Previous | Media control (playerctl) |
| Mute / Volume up / down | Volume (5% steps) |
| Brightness up / down | Brightness (5% steps) |

## Session

| Keys | Action |
|---|---|
| Super + ] | Reload Mango config |
| Super + M | Quit Mango (log out) |

## Terminal (zsh)

| Keys | Action |
|---|---|
| Esc Esc | Put `sudo` in front of the command |
| Ctrl + R | Search history (fzf) |
| Ctrl + T | Pick a file (fzf) |
| Alt + C | Jump to a folder (fzf) |
| Up / Down | Search history for what you've typed |
| Alt + Left / Right / Up | Back / forward / up a folder |
| Tab | Fuzzy completion menu |
